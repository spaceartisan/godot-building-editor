Floors
Level dimensions

For wall gaps such as a large barn entrance. Use Floor Footprint to define the slab outline. No wall or collision is added across the gap.

An edit is blocked if stairs would connect different floors. Enable the option above to remove those flights. Undo restores the complete edit. Reordering recalculates level heights; independent roofs and manual slabs keep their absolute heights.

Each story generates its floor and exposed ceiling by default. Turn either off on this floor when you want to construct that surface entirely with Manual Floor / Manual Ceiling objects. Manual roofs and manual surfaces are building-level objects with absolute heights.

Automatic surface defaults

Automatic floor thickness uses the Floor / platform thickness above. Automatic floor and ceiling generation can be enabled/disabled per story in the Floors section.

Automatic Roof

Hip / polygon follows convex outlines, including round buildings made from angled walls. Concave outlines use separate convex roof sections. Automatic roofs remain tied to exposed floors. Manual Roof objects are independent and replace the automatic roof only where they overlap at the same height.

Controls

Wall: click points; snap to the first point to close a loop. Esc finishes the run.

Room / Floor Footprint / Manual Floor / Manual Ceiling / Porch / Roof: drag a rectangle.

Door / Window: click a wall.

Ramp: drag from bottom toward the upper landing. The ramp rises smoothly to the next story.

Railing: drag a line.

Select: click a wall, then drag its A / B handles. Move connected endpoints is on by default; turn it off in Selection to detach just one endpoint. Green previews are valid, red previews are blocked. Release to apply; Esc cancels. Press Delete to remove the selection.

Move a group: Shift-click objects or drag a box from empty space. Drag a selected object, or arm Move selection and drag anywhere. Yellow dashed outlines preview the move; red means blocked. Keep wall joints moves neighboring endpoints too. Doors/windows follow their walls. Alt bypasses grid snapping.

2D: wheel zoom · middle-drag pan.

3D: left-drag orbit · wheel zoom.

Escape: finish/cancel the current drawing operation and return to Select.

Undo/Redo: Ctrl/Cmd+Z · Ctrl/Cmd+Y or Shift+Ctrl/Cmd+Z.

Godot Export

Reports describe the current checks. Save the building JSON separately for editing.

    Off by default: named material slots remain empty for authoring in Godot. Preview colors are only an editor aid.

    Exports a building .tscn plus separate door scenes. Floors, ceilings and roofs can be generated automatically or supplemented/replaced with independent absolute-height manual surfaces. Walls, stairs, platforms and supports are baked for Godot while material-facing surfaces remain independently assignable where appropriate.

    Renders the unmodified export with Godot through the local server (GODOT_BIN=/path/to/godot node server.mjs), using the same views as godot-check --render: exterior diagonals, aerial and eye-level views of labelled regions.

    Wall profile editor

    A side-on section repeated along each wall. Height levels scale with wall height; offset and horizontal thickness are metres. Standard remains the default.

    Doorway shape editor

    Draw the front outline of a doorway. Use it for an empty passage or a matching framed panel. Each doorway keeps its own width and height. Shapes may have clipped corners, arches, or concave notches. Use Undo/Redo for draft edits, or Ctrl/Cmd+Z while the canvas is focused.

    Keep a flat edge at floor level. Framed panels need room for the frame inset; use an empty opening for very narrow notches. Custom panels export a movable Panel node; configure movement in Godot.
