# v1.0 — final scoped workflow audit

The v0.33 ZIP was compared against all 299 working-source files before changes: no differences. A separate clean extraction reproduced the numeric-setting issue below. All existing 33 example plans and 64 scene assets remain unchanged; no export geometry or schema migration was introduced in this pass.

## Findings and fixes

| Finding | Resolution |
| --- | --- |
| Entering grid size 1001 committed an invalid document and reported success. Other ordinary numeric settings lacked the structural controls’ pre-commit validation. | Validate the candidate before commit, restore the original document and controls on errors, and preserve undo/redo history. Existing minimum clamps and structural-opening rules remain intact. |
| Check results were low in the scrolling properties panel; explicit checks and blocked exports did not take the user to them. | A compact Checks button near Export reflects current error/warning counts. Explicit checks, warning exports and blocked/failed exports focus and scroll to a results summary. Background validation retains focus. Errors block the download; warnings remain permitted. |
| Current guides mixed older catalog counts and capability limits with current behavior, and recipe source dependencies were scattered. | Added QUICKSTART.md with Godot import guidance and all 11 recipe/source mappings, refreshed current guides, and marked VALIDATION.md as historical. |

## Workflow evidence

- Every recipe runs from its declared source or preceding recipe. Core audit: 24 CLI calls across 11 recipes, dry-run/save hash parity, strict rejection of the intentional ineffective-roof warning, unchanged input bytes, web reload and byte-identical web/CLI exports.
- All three removal recipes restore the original building/door scene bytes exactly. Export remains scene assets and relative door dependencies, with no project.godot.
- Recipe engine audit: 13 CLI calls, 27 freshly exported scenes and 524 collision shapes; empty material slots and successful resource loading. This is a resource audit with zero additional physics rays. Dedicated floor/stair/roof/wall/door suites continue to supply physics checks.
- UI handler regressions exercise numeric rollback/history, current check states, no background focus stealing, explicit focus/scroll intent, warning export, hard-error blocking and download-failure feedback. The tests capture the real ZIP exporter at its browser download boundary.
- Final release report: seven gates, 34 core scripts and 13 engine-asset scripts. Final archive verification separately checks CRCs, hashes, modes, previous example bytes and recipe execution from a clean extraction.
